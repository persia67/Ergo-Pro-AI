# ErgoPro AI - سامانه پیشرفته و هوشمند ارزیابی ارگونومی کاربری

**ErgoPro AI** یک پلتفرم پیشرفته، تمام‌عیار و خلاقانه برای ارزیابی ارگونومیک وضعیت قرارگیری بدن (Posture) در محیط‌های کاری به صورت زنده است که با بهره‌گیری از هوش مصنوعی چندوجهی (Multimodal AI) به کارشناسان بهداشت حرفه‌ای (HSE)، متخصصان ارگونومی و کارفرمایان کمک می‌کند تا آسیب‌های اسکلتی-عضلانی در محیط کار را شناسایی و برطرف نمایند.

---

## 🌟 ویژگی‌های کلیدی پروژه (Key Features)

این بخش مهم‌ترین قابلیت‌های نرم‌افزار را بر اساس **ارزش کاربردی برای کسب‌وکارها** و **پیچیدگی فنی** معرفی می‌کند:

### ۱. دستیار هوشمند چندوجهی پردازش تصویر (Media AI Analysis)
* **تخمین زوایای بدنی با بینایی ماشین:** با آپلود تصویر یا ویدیو از کار پرسنل، هوش مصنوعی به طور خودکار زوایای بحرانی گردن، تنه، بازوها و ساعد را تحلیل کرده و امتیازات ارگونومی مربوطه را کشف و پیشنهاد می‌دهد.
* **تحلیل توصیفی مستند:** برای هر پارامتر ارائه‌شده، دلایل فنی و آناتومیک دقیقی بر اساس فریم ویدیویی ثبت می‌شود تا مرجع تصمیم‌گیری کارشناس کاملاً شفاف باشد.

### ۲. معماری هیبریدی هوش مصنوعی: آنلاین و آفلاین (Hybrid AI Engine)
* **اتصال ابری (Cloud Gemini):** استفاده از آخرین نسخه‌های مدل **Google Gemini (2.5-flash)** برای تحلیل‌های بسیار دقیق، سریع و چندزبانه.
* **هوش مصنوعی آفلاین (Ollama Offline Mode):** منحصربه‌فردترین قابلیت برای مجموعه‌هایی که مسائل محرمانگی داده‌ها دارند یا دسترسی به اینترنت در معدن یا کارگاه‌های بزرگ میسر نیست. نرم‌افزار می‌تواند به یک سرور داخلی **Ollama** بر روی شبکه محلی متصل شده و تصاویر را به وسیله مدل‌های محلی بینایی ماشین (نظیر **Llava** یا **Bakllava**) پردازش کند. این مورد از بخش **تنظیمات (Settings ⚙️)** به راحتی قابل پیکربندی است.

### ۳. پایداری داده‌ها به روش آفلاین‌محور (Local-First Architecture)
* استفاده پایدار از موتور ذخیره‌سازی **localforage** به جای LocalStorage استاندارد. این معماری به برنامه اجازه می‌دهد تا حجم‌های بزرگ تصاویر و تاریخچه‌های طولانی‌مدت ارزیابی‌ها را به شکل کاملاً امن در مرورگر (IndexedDB) ثبت و بازیابی کند؛ بدون اینکه کاربر نگران پر شدن حافظه یا کند شدن برنامه باشد.

### ۴. پوشش چهارگانه استانداردهای ارزیابی ارگونومی بین‌المللی
* **متد REBA (Rapid Entire Body Assessment):** ارزیابی کل اعضای بدن برای فعالیت‌هایی که دائماً در حال تغییر هستند.
* **متد RULA (Rapid Upper Limb Assessment):** تمرکز عمیق روی اعضای فوقانی بدن (شانه، بازو، مچ و دست‌ها).
* **متد OWAS (Ovako Working Posture Assessment):** ثبت و تحلیل سریع وضعیت‌های گوناگون پشت، بازو و پاها در صنایع سنگین.
* **معادله حمل بار NIOSH (Lifting Equation):** ترازسنجی دقیق حداکثر وزن مجاز برای کارهای حمل بار دستی به صورت خودکار.

### ۵. سازگاری بومی چاپ گزارش (Print & PDF Optimized)
* طراحی ویژه با استایل‌های منطبق بر پرینت کاغذ (`@media print`)؛ به طوری که کاربر با یک کلیک ساده می‌تواند گزارش کامل تحلیل‌ها را به صورت آراسته، تمیز و بدون المان‌های اضافی برنامه، به عنوان مستند علمی ذخیره یا چاپ نماید.

### ۶. فناوری اپلیکیشن وب پیش‌رونده (Progressive Web App - PWA)
* مجهز به پیکربندی PWA پیشرفته تحت مرورگر با قابلیت **Cashing Off-line**؛ کاربران به راحتی می‌توانند اپلیکیشن را روی گوشی‌های همراه یا دسکتاپ نصب کنند و بدون نیاز به اتصالات شبکه‌ای اینترنتی برنامه را اجرا نمایند.

### ۷. پشتیبانی دو زبانه کاملاً روان (Bilingual RTL/LTR Layout)
* رابط کاربری چند زبانه (فارسی / انگلیسی) که جهت قرارگیری کل عناصر صفحه، فونت‌های حرفه‌ای (Vazirmatn و Inter) و الگوهای انیمیشنی را با توجه به زبان انتخابی مطابقت می‌دهد.

## 🛠️ تکنولوژی‌های مورد استفاده (Tech Stack)

به منظور پیاده‌سازی سریع، ایمن و بهینه، از بروزترین ابزارها در این پروژه استفاده شده است:

* **فریمورک اصلی:** [React 18+](https://react.dev/) همراه با زبان برنامه‌نویسی **TypeScript** برای تضمین پایداری نوع‌ها.
* **سیستم ساخت:** [Vite](https://vitejs.dev/) جهت بارگذاری آنی تغییرات و خروجی فشرده سبک کلاینت.
* **طراحی رابط کاربری:** [Tailwind CSS](https://tailwindcss.com/) همراه با کنترل کلاس Dark Mode اختصاصی توسعه داده شده است.
* **هوش مصنوعی چندوجهی:** پکیج رسمی `@google/genai` به همراه ارتباط با APIهای تحت هاست محلی Ollama به صورت JSON API.
* **موتور دیتابیس لوکال:** [localforage](https://localforage.github.io/localforage/) برای مدیریت پایگاه‌داده محلی ناهمگام (Async).
* **پشتیبانی PWA:** ابزار `vite-plugin-pwa` جهت پیکربندی Service Workerها و فایل مانیفست استاندارد اندروید/دسکتاپ.

## 🚀 راهنمای راه‌اندازی و استفاده سریع

### پیش‌نیازها
مطمئن شوید که [Node.js](https://nodejs.org/) روی سیستم شما نصب است.

### مراحل نصب و اجرا

۱. وابستگی‌های پروژه را نصب کنید:
```bash
npm install
```

۲. فایل پیکربندی توکن‌های زیست‌محیطی را ایجاد نمایید (اختیاری برای استفاده ابری):
یک فایل به نام `.env` ایجاد کرده و کلید معتبر خود را درون آن قرار دهید (یا از فایل نمونه `.env.example` استفاده کنید):
```env
GEMINI_API_KEY=your_gemini_api_key_here
```

۳. سرور توسعه محلی را اجرا کنید:
```bash
npm run dev
```
برنامه در آدرس پیش‌فرض توسعه [http://localhost:3000](http://localhost:3000) در دسترس خواهد بود.

## ⚙️ آموزش نحوه پیکربندی Ollama (هوش مصنوعی آفلاین)

برای استفاده از هوش مصنوعی ارزیابی ارگونومی بدون نیاز به اینترنت، مراحل زیر را دنبال کنید:

1. نرم‌افزار **Ollama** را از وب‌سایت رسمی آن دانلود و نصب نمایید.
2. مدل پیش‌بینی تصویر بینایی ماشین (نظیر `llava`) را با دستور زیر دریافت کنید:
   ```bash
   ollama run llava
   ```
3. در محیط ویندوز یا مک، حتماً مقدار `OLLAMA_ORIGINS` را به کلاینت وب خود مجاز نمایید تا خطای CORS رخ ندهد:
   * **در لینوکس/ویندوز:** تنظیم متغیر محیطی `OLLAMA_ORIGINS="*"`.
4. از چرخ‌دنده بالای برنامه دکمه **تنظیمات (Settings ⚙️)** را باز کنید.
5. موتور هوش مصنوعی را به **Ollama (Offline)** تغییر دهید.
6. آدرس پیش‌فرض `http://localhost:11434` و نام مدل (`llava`) را ذخیره نمایید. اکنون می‌توانید وضعیت‌ها را به صورت محلی و کاملاً آفلاین تحلیل کنید!
